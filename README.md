## How to Use

1. **View the Website**
   - Open `index.html` in a web browser
   - Or visit `http://localhost:8000` if server is running

2. **Customize Content**
   - Edit text in `index.html` for clinic information
   - Replace image paths with your own images
   - Update service descriptions as needed

3. **Modify Colors**
   - Edit CSS variables in `styles.css` (`:root` section)
   - Change `--primary-color`, `--secondary-color`, etc.

4. **Add Real Backend**
   - Replace form submission in `script.js` with API calls
   - Connect to appointment management system
   - Integrate email notifications
